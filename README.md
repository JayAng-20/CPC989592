# 台灣中油加油回饋精算與排名

一個可離線部署、可直接放上 GitHub Pages 的台灣中油加油比較網站。它會以 98、95、92 無鉛汽油牌價，精確比較六種加油方式的回饋、有效每公升成本與動態排名；另提供「跳停後金額試算」頁面。

網站全部使用繁體中文、HTML、CSS、Vanilla JavaScript 與 Node.js 內建功能，不使用 CDN、資料庫、前端框架或第三方套件。

## 兩個頁面

### 1. 加油回饋排名

入口：[index.html](index.html)

功能包含：

- 台灣中油 98、95、92 官方公告牌價。
- 三種油品各自的最佳方案摘要。
- 六種加油方式的精確有效回饋率長條比較。
- 98、95、92 分頁式完整動態排名。
- 三油品綜合比較表。
- 進階參數：本金、捷利卡回饋率、自助折扣、卡別、中信紅利點數價值與 VIP 點數估值。
- 淺色、深色與跟隨系統主題。
- 手機、平板、桌面響應式版面。
- localStorage 記住進階設定、牌價快照與手動主題偏好。

### 2. 跳停後金額試算

入口：[rounding.html](rounding.html)

此頁沿用第一頁同步的 98、95、92 油價與自助每公升優惠，不需要再次輸入油價。

功能包含：

- 選擇 98、95、92 無鉛汽油。
- 選擇人工加油或自助加油。
- 輸入目前跳停公升數，最多兩位小數。
- 從「目前公升數 + 0.01 L」開始，只向上搜尋。
- 人工模式直接使用人工牌價 × 候選公升數。
- 自助模式直接使用自助有效單價 × 候選公升數，不重複扣折扣，也不二次四捨五入。
- 金額範圍固定為 NT$20～NT$3,000。
- 搜尋兩種候選條件：
  - 小數部分介於 0.300（含）至 0.400（不含）：最多五項。
  - 小數部分精確等於 0.400：最多五項。
- 兩類結果合併後，依「還需增加」公升數由少到多排序，合計最多十項。
- 顯示目標公升數、還需增加的 L／mL、未進位金額與四捨五入後整數金額。
- 精確等於 `.400` 的候選金額以紅色強調。

## 回饋計算公式

### 中信紅利

御璽卡：

```text
中信紅利點數 = floor(A ÷ 30) × 3
中信紅利價值 = 中信紅利點數 × 每點價值
```

白金卡：

```text
中信紅利點數 = floor(A ÷ 30) × 2
中信紅利價值 = 中信紅利點數 × 每點價值
```

### 捷利卡儲值

```text
B = A × (1 + r)
捷利卡紅利金 = B − A
```

### 自助加油

```text
自助有效單價 U = 牌價 P − 自助每公升折扣 d
可加公升數 = 預算 ÷ U
自助折讓 = 可加公升數 × d
```

自助折扣有兩種不同的比較角度：

```text
一般廣告式折扣比例 = d ÷ P × 100%
相同本金下的額外購買力 = d ÷ U × 100%
```

油價愈低，固定 NT$0.8 折扣相對占比愈高；油價愈高，自助加油的相對優勢會下降。

### 精確有效回饋率

```text
總回饋 = 捷利卡紅利金 + 自助折讓 + 中信紅利價值 + VIP 點數價值
精確有效回饋率 = 總回饋 ÷ A × 100%
有效每公升成本 = (A − 中信紅利價值 − VIP 點數價值) ÷ 可加公升數
```

自助方案另以以下公式交叉驗證：

```text
總回饋 = 牌價 P × 可加公升數 + 中信紅利價值 − A
```

### 廣告式回饋率與精確有效回饋率

廣告式回饋率會把固定百分比、紅利估值與 `d ÷ P` 直接相加。精確有效回饋率則先以實際可用預算及自助單價算出可加公升數，再將所有回饋換算回同一筆本金。

因此兩者不一定相同；網站同時顯示兩種數值及差異。

### VIP 折油與購買副產品的差異

- 「VIP 購買副產品」：每點以 NT$0.01 估值，適用於複合商店、洗車或快保等用途。這不是現金回饋，也不代表可以用相同價值折抵油錢。
- 「VIP 折抵油錢」：每點以 NT$0.005 估值。以每消費 NT$1 給 2 點為例，油費折抵價值約為 1%。

## 跳停後試算的精確計算方式

跳停頁面不使用一般 JavaScript 浮點數的小數比較，而是採用 fixed-point 整數化運算：

```text
單價 32.0 元/L → 320 個 0.1 元單位
公升數 10.01 L → 1001 個 0.01 L 單位
320 × 1001 = 320320
換算為未進位金額 = NT$320.320
```

以此可安全判斷金額小數部分，避免 `0.399999999` 或 `0.400000001` 的二進位浮點數誤差。

## 自動油價更新

### GitHub Pages

GitHub Pages 是靜態網站。使用者開啟網站時，瀏覽器不會、也不應該直接取得有寫入權限的 GitHub 憑證來啟動更新。

專案透過 GitHub Actions 的 [update-cpc-prices.yml](.github/workflows/update-cpc-prices.yml) 更新 [data/cpc-prices.json](data/cpc-prices.json)：

- 每日台灣時間約 00:17 檢查一次。
- 每週一台灣時間約 01:17、02:17 額外重試。
- 可在 GitHub Actions 手動執行。
- 只有官方牌價真的變動時才建立 commit。
- 更新前先執行全部自動化測試。
- 工作流程失敗時，GitHub Pages 仍保留上一份有效資料檔。

GitHub Pages 上的「更新最新牌價」按鈕會重新讀取目前已部署的牌價快照；真正的資料更新由 Actions 排程或手動工作流程處理。

### 本機 Node 伺服器

本機啟動網站時使用：

```bash
npm run serve
```

預設網址：

```text
http://127.0.0.1:8080/
```

本機伺服器會：

1. 啟動時立即向台灣中油官方 JSON 檢查牌價。
2. 每次網頁載入時檢查同步狀態；五分鐘內已有成功結果時共用快取。
3. 每六小時做背景檢查。
4. 點擊「更新最新牌價」時強制重新查詢。
5. 多個頁面同時請求時共用同一個更新工作。
6. 新資料通過完整格式、單位、日期與三種油品驗證後，才安全寫入資料檔。
7. 官方來源暫時失敗時，保留上一份有效快照並顯示狀態。

可單獨執行一次更新：

```bash
npm run update:prices
```

直接雙擊 `index.html`（`file://`）時，若瀏覽器安全政策阻擋讀取相鄰 JSON，網站會安全改用內嵌離線牌價快照，因此仍可完整操作計算與兩個頁面；但無法直接向官方同步。請使用 `npm run serve` 才能使用本機即時更新。

## 部署到 GitHub Pages

1. 將此資料夾內所有檔案上傳至 GitHub 儲存庫根目錄。
2. 在 GitHub 儲存庫開啟 **Settings → Pages**。
3. Source 選擇 **Deploy from a branch**。
4. Branch 選擇 `main`，資料夾選擇 `/(root)`。
5. 儲存後等待 Pages 完成部署。
6. GitHub Pages 專案網站通常會是：

```text
https://你的帳號.github.io/儲存庫名稱/
```

所有 HTML、CSS、JavaScript、JSON 和頁面導覽皆採相對路徑，可在例如 `/CPC989592/` 這類專案子路徑下運作。

部署後請確認 GitHub Actions 有權寫入內容：

- 工作流程已設定 `permissions: contents: write`。
- 儲存庫的 Actions 權限需允許 workflow 寫入內容。
- 如需立即取得新版牌價，可在 **Actions → 更新台灣中油官方油價 → Run workflow** 手動執行。

## 重要說明

1. 自助加油不能累積中油 VIP 點數。
2. 中信紅利在信用卡付款或儲值時取得；使用捷利卡加油時不會再次取得中信紅利。
3. VIP 購買副產品估值不是現金回饋，也不是相同價值的折油回饋。
4. 電子點數、紅利與活動仍可能有使用門檻、兌換單位及適用範圍。
5. 本工具是數學比較工具；實際資格、牌價及活動規則以台灣中油與中國信託正式公告為準。
6. 所有排名依目前資料快照與使用者進階設定即時計算。
