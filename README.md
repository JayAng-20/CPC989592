# 比較各種情況哪種方式加油比較划算-台灣中油版

這是一個可離線執行的雙頁靜態網站。第一頁依使用者輸入的台灣中油 98、95、92 無鉛汽油牌價，統一比較六種捷利卡／中油 Pay、自助／人工加油方式；第二頁「跳停後金額試算」沿用同一組油價，向上搜尋最近五個未進位金額小數部分精確等於 `0.400` 的候選公升數。

首頁依序呈現「封面標題 → 輸入油價 → 三種油品最佳方案 → 精確有效回饋率圖表 → 98／95／92 單一油品動態排名 → 三油品綜合比較表」。完整排名使用三個按鈕切換，同一時間只顯示一張油品表格，原有欄位、手機排名卡與詳細公式均完整保留。

網站只使用 HTML、CSS 與 Vanilla JavaScript，沒有後端、資料庫、外部 API、CDN 或第三方圖表套件。所有計算都在瀏覽器本機完成。

## 開始使用

最簡單的方式是直接用瀏覽器開啟 `index.html`。本站使用一般 JavaScript 檔案而非 ES module，因此單頁功能也支援以 `file://` 直接執行。由於不同瀏覽器對兩個 `file://` 頁面共用 localStorage 的處理可能不同，若要完整使用兩頁油價同步，建議啟動本機靜態伺服器。

若希望以本機靜態伺服器執行，可在此資料夾使用：

```bash
python3 -m http.server 8080
```

再開啟 `http://localhost:8080/`。

專案檔案：

- `index.html`：精簡後的完整頁面結構與排名切換控制
- `rounding.html`：「跳停後金額試算」頁面結構與輸入介面
- `assets/hero-cover.png`：離線使用的高端抽象商業封面圖
- `styles.css`：兩頁共用的響應式尊貴玻璃質感、深淺色模式與結果樣式
- `calculator.js`：獨立純計算函式、驗證、排名、損益兩平、共用單價規則與 localStorage 工具
- `app.js`：表單狀態、DOM 呈現、即時更新、圖表與排名油品切換
- `rounding-calculator.js`：跳停後候選值的 fixed-point 純計算函式

- `package.json`：測試與本機伺服器快捷指令

## 跳停後金額試算

從任一頁頁首的雙頁導覽選擇「跳停後金額試算」，即可前往 `rounding.html`；按「加油回饋排名」可返回 `index.html`。第二頁不會要求重複輸入油價，而是讀取第一頁最後一組合法且完整的 98、95、92 牌價，以及同一組自助每公升優惠。

操作方式：

1. 先在「加油回饋排名」頁面設定 98、95、92 牌價。
2. 前往「跳停後金額試算」。
3. 選擇 98、95 或 92 無鉛汽油。
4. 選擇人工加油或自助加油。
5. 輸入目前跳停公升數，最多到小數點後兩位；頁面會立即更新，也可按「開始試算」。

搜尋只會從「目前跳停公升數 + 0.01 L」開始向上增加，不會包含跳停值本身或任何更低的公升數。每個候選值使用選定模式的有效單價直接乘以候選公升數；未進位金額必須位於 `NT$20～NT$3,000`，且金額小數部分必須精確等於 `0.400`。結果依還需增加的公升數由少到多排列，最多顯示最近五項。

人工與自助的單價規則為：

```text
人工未進位金額 = 人工牌價 × 候選公升數
自助有效單價 = 人工牌價 − 第一頁設定的自助每公升優惠
自助未進位金額 = 自助有效單價 × 候選公升數
```

自助模式不會先算人工總額、不會另行四捨五入折扣，也不會在整數金額上再次扣除優惠。

### 精確十進位計算

第二頁不使用 JavaScript 二進位浮點數直接判斷小數部分是否精確等於 `0.400`。價格會解析成 BigInt 十進位係數 `p` 與位數 `s`，公升數則解析成百分之一公升整數 `v`：

```text
有效單價 = p ÷ 10^s 元／L
候選公升數 = v ÷ 100 L
未進位金額分子 = p × v
未進位金額分母 D = 10^(s + 2)
小數部分 F = 未進位金額分子 mod D
符合候選 ⇔ 5 × F = 2 × D
四捨五入後整數元 = floor((2 × 未進位金額分子 + D) ÷ (2 × D))
```

因此 `NT$320.4`、`NT$320.40`、`NT$320.400` 與 `NT$320.4000` 都會列入；`NT$320.399`、`NT$320.401`、`NT$320.410`、`NT$320.490`、`NT$320.499`、`NT$320.500` 與 `NT$320.000` 都不會列入。搜尋起點與 `NT$3,000` 對應的最大公升數都由整數公式推導，迴圈有明確終點。

兩頁共用的 localStorage key 為：

```text
cpc-fuel-rewards-calculator:v1
```

第二頁會嚴格確認儲存資料中同時存在 98、95、92 與自助優惠，缺少任一項時不會以預設值補猜，而會提示先回首頁設定油價。

## 共用計算定義

令：

- `A`：實際拿出的比較本金
- `r`：捷利卡儲值回饋率（例如 4% 在程式內為 `0.04`）
- `P`：汽油牌價
- `d`：自助每公升固定折扣
- `B`：捷利卡儲值後總可用餘額
- `U`：自助實際單價

共用公式：

```text
B = A × (1 + r)
捷利卡紅利金 = B − A
U = P − d

御璽卡中信紅利點數 = floor(A ÷ 30) × 3
白金卡中信紅利點數 = floor(A ÷ 30) × 2
中信紅利價值 = 中信紅利點數 × 中信紅利每點價值
```

中信紅利依「每滿 30 元」取整，不能用 `A × 0.8%` 取代。使用捷利卡加油時不會再次取得中信紅利。

## 六種方案與公式

以下所有內部運算都保留 JavaScript 浮點數完整精度，只在畫面顯示時四捨五入。

### 方法 1：星期一儲值後自助加油

```text
可加公升數 = B ÷ U
自助折讓 = 可加公升數 × d
總回饋 = 捷利卡紅利金 + 自助折讓 + 中信紅利價值
精確有效回饋率 = 總回饋 ÷ A × 100%
總等值 = A + 總回饋
有效每公升成本 = (A − 中信紅利價值) ÷ 可加公升數
廣告式回饋率 = r + 中信紅利價值 ÷ A + d ÷ P
```

交叉驗證：

```text
總回饋 = P × 可加公升數 + 中信紅利價值 − A
```

### 方法 2：星期一儲值後人工加油，VIP 購買副產品

```text
可加公升數 = B ÷ P
VIP 點數 = floor(B) × 每元 VIP 點數
VIP 價值 = VIP 點數 × VIP 購買副產品每點價值
總回饋 = 捷利卡紅利金 + 中信紅利價值 + VIP 價值
精確有效回饋率 = 總回饋 ÷ A × 100%
總等值 = A + 總回饋
有效每公升成本 = (A − 中信紅利價值 − VIP 價值) ÷ 可加公升數
廣告式回饋率 = r + 中信紅利價值 ÷ A + 每元 VIP 點數 × VIP 購買副產品每點價值
```

預設每點以 0.01 元估值，適用於複合商店、洗車或快保；這不是 2% 現金回饋，也不能直接用相同價值折抵油錢。

### 方法 3：星期一儲值後人工加油，VIP 折抵油錢

```text
可加公升數 = B ÷ P
VIP 點數 = floor(B) × 每元 VIP 點數
VIP 價值 = VIP 點數 × VIP 折油每點價值
總回饋 = 捷利卡紅利金 + 中信紅利價值 + VIP 價值
精確有效回饋率 = 總回饋 ÷ A × 100%
總等值 = A + 總回饋
有效每公升成本 = (A − 中信紅利價值 − VIP 價值) ÷ 可加公升數
廣告式回饋率 = r + 中信紅利價值 ÷ A + 每元 VIP 點數 × VIP 折油每點價值
```

預設每點以 0.005 元估值；每元 2 點時，油費價值約為 1%。

### 方法 4：中油 Pay 直接刷聯名卡自助加油

```text
可加公升數 = A ÷ U
自助折讓 = 可加公升數 × d
總回饋 = 自助折讓 + 中信紅利價值
精確有效回饋率 = 總回饋 ÷ A × 100%
總等值 = A + 總回饋
有效每公升成本 = (A − 中信紅利價值) ÷ 可加公升數
廣告式回饋率 = 中信紅利價值 ÷ A + d ÷ P
```

交叉驗證：

```text
總回饋 = P × 可加公升數 + 中信紅利價值 − A
```

### 方法 5：中油 Pay 直接刷聯名卡人工加油，VIP 購買副產品

```text
可加公升數 = A ÷ P
VIP 點數 = floor(A) × 每元 VIP 點數
VIP 價值 = VIP 點數 × VIP 購買副產品每點價值
總回饋 = 中信紅利價值 + VIP 價值
精確有效回饋率 = 總回饋 ÷ A × 100%
總等值 = A + 總回饋
有效每公升成本 = (A − 中信紅利價值 − VIP 價值) ÷ 可加公升數
廣告式回饋率 = 中信紅利價值 ÷ A + 每元 VIP 點數 × VIP 購買副產品每點價值
```

### 方法 6：中油 Pay 直接刷聯名卡人工加油，VIP 折抵油錢

```text
可加公升數 = A ÷ P
VIP 點數 = floor(A) × 每元 VIP 點數
VIP 價值 = VIP 點數 × VIP 折油每點價值
總回饋 = 中信紅利價值 + VIP 價值
精確有效回饋率 = 總回饋 ÷ A × 100%
總等值 = A + 總回饋
有效每公升成本 = (A − 中信紅利價值 − VIP 價值) ÷ 可加公升數
廣告式回饋率 = 中信紅利價值 ÷ A + 每元 VIP 點數 × VIP 折油每點價值
```

方法 2／5 的「約 2%」與方法 3／6 的「約 1%」只描述預設的點數取得率與估值；修改進階設定後，實際比例會跟著變動。

## 廣告式回饋率與精確有效回饋率

「廣告式回饋率」把名目儲值率、中信紅利比例、自助 `d ÷ P` 或每元 VIP 點數估值直接相加。這種算法容易閱讀，但各項回饋的實際計算基準可能不同。

「精確有效回饋率」先算出實際取得的紅利金、完整公升數、固定折扣帶來的真正折讓、按 `floor` 取得的點數及其估值，再統一除以實際拿出的本金 `A`：

```text
精確有效回饋率 = 實際總回饋 ÷ A × 100%
精確與廣告式差異 = 精確有效回饋率 − 廣告式回饋率
```

差異以「個百分點」表示，可能為正、零或負；不能把它當成百分比倍數。

## 固定 0.8 元折扣為何會隨油價改變效益

```text
廣告式折扣比例 = d ÷ P × 100%
固定本金的實際額外購買力 = d ÷ (P − d) × 100% = d ÷ U × 100%
```

兩者分母不同，因此數值不相同。牌價愈低，固定 0.8 元占牌價的比例愈高；牌價愈高，自助方案的相對優勢會降低，人工加油搭配 VIP 購買副產品可能反而超越自助方案。自助折扣不是固定百分比，所以排名不能寫死。

## 損益兩平油價

比較同一付款情境下的自助折讓與人工 VIP 價值時，共同的捷利卡紅利與中信紅利會互相抵銷。令 `X` 為該情境的可用金額（儲值為 `B`、直刷為 `A`），`V` 為對應人工方案的 VIP 點數總價值：

```text
X × d ÷ (P − d) = V
P = d + X × d ÷ V
```

網站分別計算以下四組，不共用寫死的答案：

1. 儲值後自助 vs 儲值後人工 VIP 購買副產品
2. 儲值後自助 vs 儲值後人工 VIP 折油
3. 直接刷卡自助 vs 直接刷卡人工 VIP 購買副產品
4. 直接刷卡自助 vs 直接刷卡人工 VIP 折油

預設參數求得約為 `40.8／80.8／40.8／80.8` 元／公升。牌價低於交點時自助較有利；高於交點時對應的人工 VIP 方案可能較有利。若折扣或 VIP 估值為 0，網站會明示沒有有限的正牌價交點。

## 修改預設參數

一般使用者可直接在頁面「進階設定」調整，不必修改程式。

若要永久更改第一次開啟網站時的預設值，編輯 `calculator.js` 頂端的 `DEFAULT_PRICES` 與 `DEFAULT_CONFIG`。已經使用過網站的瀏覽器可能保留舊設定，可按「恢復預設值」或清除該網站的 localStorage。

目前可調整的活動規則包括：

- 比較本金與星期一儲值回饋率
- 自助每公升固定折扣
